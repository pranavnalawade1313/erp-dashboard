 # 🛒 Grocery Shop ERP Dashboard

A modern, responsive, and feature-rich ERP Dashboard developed using **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Recharts**. The application provides an intuitive interface for managing daily grocery store operations, including inventory, sales, purchases, customers, suppliers, employees, finance, and business analytics.
